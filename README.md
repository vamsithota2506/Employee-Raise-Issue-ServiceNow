# Employee Raise Issue – ServiceNow

## Project Overview

This project is a custom ServiceNow application designed to allow employees to raise workplace issues and track their requests.

## Application

- Application Name: Employee Raise Issue
- Platform: ServiceNow
- Application Type: Scoped Application

## Phase 1 – Custom Application

The custom ServiceNow application was created with the required application scope and configuration.

## Phase 2 – Custom Table

A custom table named `Employee Issue` was created to store employee issue records.

The table uses automatic numbering for issue records.

## Technologies

- ServiceNow
- ServiceNow Studio
- Service Portal
- Record Producer

## Project Status

Phase 1: Custom Application – Completed
Phase 2: Custom Table – In Progress
